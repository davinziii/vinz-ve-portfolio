# Design revision — Vinz de Leon

## Changes

A photo and stacked Vinz / de Leon wordmark replace the abstract V/M identity. A new casual portrait leads the warm, light landing page. The featured-work section is dark; the gallery remains light. Self-hosted Manrope provides one consistent family. Main body text is 16–17px; supporting categories and controls stay at least 13px. Removed numbered section labels, tiny uppercase file IDs, decorative orbit/star art, and repeated marketing slogans. Contact links now use the supplied email address. Existing media, filters, dialogs and motion remain functional.

## Research and interpretation

- [Indra — Video Editor Portfolio, Dribbble](https://dribbble.com/shots/22184938-Video-Editor-Portfolio): viewed the design, including a prominent personal portrait, direct introduction and straightforward contact action. Used that personal emphasis as inspiration, without copying the layout or client imagery.
- [Modern Artist — Portfolio of a video editor, Dribbble](https://dribbble.com/shots/22500202-Portfolio-of-a-video-editor): reviewed the project description and its stated vibrant-color direction.
- [Creative Portfolio Website, Behance](https://www.behance.net/gallery/240644569/Creative-Portfolio-Website-Mini-Design-Project): search-indexed description presents multidisciplinary work through a minimal structured interface. The full page returned 403; it was not visually verified.
- [Minimal portfolio for multi creative, Behance](https://www.behance.net/gallery/207589769/Minimal-portfolio-website-for-multi-creative): located as a related reference; the full page returned 403.
- [Nielsen Norman Group — 5 Principles of Visual Design](https://www.nngroup.com/articles/principles-visual-design/): hierarchy, scale, balance and restrained type sizing informed the simplified page.
- [Nielsen Norman Group — Legibility, Readability, Comprehension](https://www.nngroup.com/articles/legibility-readability-comprehension/): larger readable text and clear writing informed the removal of microcopy.

These are inspiration sources and design rationale, not usability-test findings about this portfolio.
